# 自己資金管理アプリ

ブラウザだけで動く、個人向けの資金管理アプリです。サーバーやインストールは不要で、`index.html` をブラウザで開くだけで使えます。

## 機能

- **ダッシュボード**: 月末時点の総資産、今月の収入・支出・収支、カテゴリ別支出、予算の消化状況、直近6か月の推移グラフ
- **取引**: 収入・支出・口座間の振替を登録／編集／削除、メモ・カテゴリでの検索
- **口座**: 現金・銀行など複数口座の残高管理（開始残高を設定可能）
- **予算・設定**: 支出カテゴリ別の月予算（80%で黄色、超過で赤表示）、カテゴリの追加・削除
- **データ**: JSON でバックアップ／復元、CSV 書き出し（Excel 対応）

## 使い方

1. `index.html` をブラウザで開く
2. 「口座」タブで口座の開始残高を設定する
3. 「取引」タブで収入・支出を記録する
4. 画面右上で表示する月を切り替える

## データの保存について

データはブラウザの localStorage にのみ保存され、外部には送信されません。
ブラウザのデータを消去すると失われるため、「予算・設定」タブから定期的に JSON バックアップを取ってください。

## 開発

```
npm test   # 計算ロジック（js/core.js）の単体テスト
```

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面構成 |
| `css/styles.css` | スタイル（ダークモード対応） |
| `js/core.js` | 残高・集計・予算などの計算ロジック（DOM 非依存） |
| `js/app.js` | 画面描画とイベント処理 |
| `tests/core.test.js` | `core.js` の単体テスト |
